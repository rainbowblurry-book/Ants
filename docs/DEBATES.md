# Haiku Debates (DR-001, DR-002, DR-003)

Voices: **GD** Game Designer · **AD** Art Director · **TL** Tech Lead. 3 rounds each. Judged in `DECISIONS.md`.

## Debate 1 — Art style (DR-001)
**R1**
GD: *Read the shot at once / clear edge, bold ground, tiny ants / Flash makes outlines sing*
AD: *Paper cutouts, warm / layered shadows, glued-on charm / craters scallop soft*
TL: *Flat fills, gradients / one atlas, small and tidy / phones stay cool and fast*
**R2**
GD: *Doodle lines wobble / ants hide in the scribbled sky / clarity first, please*
AD: *Cutouts cast shadows / stacked layers burn mid-range fill / Flash gloss wins, I yield*
TL: *Doodle needs wobble / shaders on every crater / Vector is cheap, crisp*
**R3**
GD: *One outline, one glance / Flash world, glossy buttons, win / ants pop from the green*
AD: *Rim-lit rounded ground / bold dark outline, bright fill, glow / I vote Flash, with warmth*
TL: *My vote: Flash vector / outline from the terrain mask / curves come for free, ship*
**Verdict:** Flash-style vector world, unanimous.

## Debate 2 — Starter weapons (DR-002)
**R1**
GD: *Three roles: shoot, bounce, spread / seed, dewdrop, pollen: all tools / each asks a new thing*
AD: *Puffed cheeks, spitting seed / dewdrop jiggles, googly-eyed / pollen sneezes gold*
TL: *Seed flies straight and cheap / dewdrop bounce, fixed-step physics / pollen: seeded rolls*
**R2**
GD: *Seed is too plain? No. / the basic shot teaches wind / bounce teaches patience*
AD: *Dewdrop wobbles, splats / ants wear soggy hats of foam / pollen: yellow snow*
TL: *Pollen holes: five stamps / circle masks, cheap to erase / no shader needed*
**R3**
GD: *Seed, Dewdrop, Pollen / wind, time, spread: three lessons learned / ship the trio now*
AD: *Dot, drop, puff: clear shapes / each with its own sound and splash / I vote yes, giggling*
TL: *Three physics paths, fixed / replays match on every phone / aye, ship it today*
**Verdict:** Seed Spitter, Dewdrop Bounce, Pollen Pod.

## Debate 3 — UI style (DR-003)
**R1**
GD: *Thumbs live in corners / aim left, big Go button right / targets stay roomy*
AD: *Jelly buttons, thick / dark plum outline, one bright glint / candy, not plastic*
TL: *Nine-slice rounded skins / fonts as bitmap atlas, crisp / cheap on mid-range phones*
**R2**
GD: *Bark panels are dull / wood hides the wind arrow clue / jelly pops, I read*
AD: *Stickers: white borders / charming, but they clutter small / jelly, outlined, wins*
TL: *Leaf textures cost RAM / jelly is flat fills and glints / light on memory*
**R3**
GD: *Jelly, then. Two teams: / circle blue, triangle gold / shape tells, color helps*
AD: *Plum ink, cream, candy / one curved glint per button, flat / no mush gradients*
TL: *Fonts: free, OFL / Lilita One, Nunito / ship it, thumbs rejoice*
**Verdict:** Jelly candy UI.
